# 💚 NETRUNNER // CHAT PRIVADO CYBERPUNK

Chat estilo terminal hacker, verde, nosso canal seguro. Dois PCs conectados. É isso.

## Como usar

```bash
npm install
npm start
```
Depois dele, abra o navegador em dois dispositivos na mesma rede, acesse `http://<IP-do-servidor>:3000`, informe o codinome e... divirta-se.

## Recursos
- WebSocket privado
- Temas e efeito de terminal verde o dia inteiro
